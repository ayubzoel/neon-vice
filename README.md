Neon Vice is a 3D open-world action game inspired by GTA 6: a small, smooth Vice Harbor map with no bugs — open streets, drivable cars, missions, a wanted system and shops, playable on PC and mobile. Built as the second, leaner take on the "Make GTA 6" bounty: a compact map done right instead of a huge one done half-way.

Play it now: https://ayubzoel.github.io/neon-vice/game/

## Run it

```sh
node serve.ts --port 8097
# then open http://localhost:8097/
# on the same Wi-Fi, phones can open it via LAN: node serve.ts --port 8097 --host 0.0.0.0
```

## Controls

| Keys | Action |
| --- | --- |
| WASD / arrows | Move (A/D turn) · Shift run |
| E | Enter/exit car, interact, shop |
| H | Holster / draw weapon · 1/2 switch pistol / SMG |
| M | Map + GPS |
| B | Backpack (weapons, jackets, stats) |
| Esc / P | Settings (audio, graphics quality, controls, save) |

On phones: left stick to move (push far to run), on-screen CAR / JUMP / FIRE / GUN / RUN buttons, ENTER to drive.

## Features

- Vice Harbor, a compact 1200×900 m night city: street grid, beach and water, park, plaza, worship and vital buildings (hospital, police).
- 12 main missions plus repeatable side jobs (taxi, parcel, race) — Vera Cruz must clear a $50,000 debt.
- Wanted system (max 3 stars, decays over time), drivable cars and a boat, pistol + SMG with ammo shops.
- Shops (Ammo-Nation, Vice Threads), save/load, day/night cycle with rain, pedestrians and traffic, PC + mobile play.
